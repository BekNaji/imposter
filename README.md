# Imposter Game

Flutter-da yaratilgan "social deduction" janridagi mantiqiy o'yin. O'yinchilar topshiriqlarni bajarishi va oralaridagi "Ayg'oqchi"ni topishlari kerak.

## Imkoniyatlari

* **Rollar:** Avtomatik "Crewmate" va "Imposter" rollari.
* **Vazifalar:** Qiziqarli mini-o'yinlar va topshiriqlar.
* **Ovoz berish:** Shubhali o'yinchilarni aniqlash uchun ovoz berish tizimi.
* **Multi-platforma:** Android, iOS va Desktop-da ishlaydi.

## Ishga tushirish

1. `flutter pub get`
2. `flutter run`
